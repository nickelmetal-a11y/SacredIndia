## 📱 12 CORE TABS (App Navigation)

### 1. 🏠 **HOME TAB** — First Screen / Dashboard
**Purpose:** GPS-aware, panchang-aware, WhatsApp-connected entry point

**Features:**
- [x] **GPS → Nearest Sacred Site**

  - Show nearest site across all 7 faiths instantly
  - Display: exact distance, founding story, what to do right now
  - Path: Home → Allow Location → Nearest site card at top

- [x] **Panchang & Namaz Timing (NEW)**
  - Hindu/Buddhist/Jain: live tithi, nakshatra, auspicious indicator
  - Islam: calculated Fajr–Isha for 7 Indian cities
  - Path: Home → Panchang widget → Share panchang to WhatsApp
  - Benefit: Visit at the right time, always

- [x] **WhatsApp Quick Actions**
  - Four one-tap WA actions:
    1. Share daily panchang
    2. Share trip plan
    3. Book a puja
    4. Request a new site
  - Pre-formatted messages
  - Path: Home → WA Quick Actions bar → Opens WhatsApp

  - Light a diya, candle, chirag, or butter lamp for someone

  - Users never delete this feature (high retention)
  - Path: Home → Light a lamp → Dedicate to person → Share to WA
